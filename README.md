## Slide Navigation & Keyboard Controls

The presentation is built with an interactive 3D Flip Card architecture running in pure HTML5, CSS3, and vanilla JavaScript (no dependencies, no build step required).

* **Navigate Slides:** `→` / `Space` / `PageDown` (Next) | `←` / `PageUp` (Previous)
* **Flip Active Cards:** `X` or `Tab` (Flips all cards on the current slide simultaneously)
* **Single Card Flip:** Click on any individual card
* **Toggle Theme:** `T` (Switches between Empathetic Light Editorial and Obsidian Dark)
* **Toggle Fullscreen:** `F` (Preserves exact non-distorting 1380×790px keynote proportions)
* **Toggle Header Dropdown:** `H` (or click top dropdown tab)
* **Toggle Footer Controls:** `C` (or click bottom pull-up tab)
* **Quick Jump:** `Home` (Slide 1) | `End` (Slide 12)
